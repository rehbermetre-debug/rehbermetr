Firebase Console → Firestore Database → Rules sekmesine git, mevcut kuralların yerine
aşağıdakini yapıştır ve "Publish" (Yayınla) butonuna bas.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Bu kural, siteye giren herkesin (anonim oturum açtıktan sonra) veri okuyup
yazabilmesine izin verir. Gerçek erişim kontrolü uygulamanın kendi kod
sistemi (öğrenci kodu / koç kodu) üzerinden sağlanıyor — bu kurallar sadece
Firebase'in "kimliksiz hiç kimse giremesin" güvenlik tabanını karşılıyor.
